# SLC-GQIDS-GetLogFile

A GQI DataSource to get a specific log file from the DataMiner System.

It supports both element log files and DM system log files.
When requesting a log file from a DataMiner that is different from the one you are connected to, always define the DataMiner ID as input argument.

Log files can be retrieved through the Get Log File custom data source.
